Eliminar favoritos de TikTok Web

Esta página genera un userscript para ejecutarlo directamente en TikTok Web. Una página web normal no puede controlar otra pestaña de TikTok por las restricciones de seguridad del navegador.

Instálalo con Tampermonkey/Violentmonkey en un navegador compatible y abre TikTok Web. Aparecerá un pequeño panel para iniciar/detener el proceso.
